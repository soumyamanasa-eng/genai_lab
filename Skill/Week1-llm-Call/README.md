# Week 1 – Calling an LLM using Gemini API

## Aim
To build a Python application that connects to a Large Language Model using the Gemini API and generates responses based on user prompts.

## Objectives
- Understand how to access an LLM through an API.
- Configure and use a Gemini API key.
- Connect Python to the Gemini model.
- Send prompts to the LLM.
- Receive and display AI-generated responses.

## Technologies Used
- Python 3.12
- Google Gemini API
- Google Gen AI SDK
- python-dotenv
- Visual Studio Code
- Google AI Studio

## Output

The program sends a prompt to the Gemini API and displays the generated response in the terminal.

### Sample Prompt
```text
What is Artificial Intelligence? Explain in simple words.
```

### Sample Output
```text
Artificial Intelligence is technology that enables
machines and computers to perform tasks that
normally require human intelligence.

It can help machines learn, solve problems,
understand language, and make decisions.
```

## Results
The Python application successfully connected to the Gemini API and generated a response based on the given prompt. The experiment demonstrated how an LLM can be accessed through an API using Python.

## Conclusion
The experiment demonstrated the basic integration of Python with the Gemini API. It helped understand how prompts are sent to a Large Language Model and how AI-generated responses are received and displayed.
